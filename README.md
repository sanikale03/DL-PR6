## 🧠 Transformer Concepts Covered

### 1. Self-Attention

Each token is projected into a Query (Q), Key (K) and Value (V). Query–Key scores are passed through softmax to produce attention weights, which combine Value vectors. Self-attention allows token representations to incorporate information from other tokens in the sequence.

### 2. Scaled Dot-Product Attention

The score matrix is calculated as:

\[
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
\]

Dividing by \(\sqrt{d_k}\) helps control score magnitudes and prevents softmax from becoming excessively saturated.

### 3. Multi-Head Attention

Multiple attention heads learn different projections and token relationships. Their outputs are concatenated and mixed by an output projection.

### 4. Positional Encoding

Self-attention alone does not encode token order. Positional information is therefore added to token representations or incorporated through learned/relative position mechanisms.

### 5. Layer Normalization

LayerNorm normalizes features within each token representation. Unlike BatchNorm, it does not rely on statistics aggregated across a batch of examples.

### 6. Encoder and Decoder Attention

Encoder-only models such as DistilBERT use bidirectional attention. Decoder-only models such as GPT-2 use causal masking so a token cannot attend to future tokens. Encoder-decoder models such as T5 combine encoder attention, decoder self-attention and cross-attention.

### 7. Cross-Attention and Inference

In cross-attention, decoder queries attend to encoder keys and values. Autoregressive generation predicts one token at a time; a KV cache can avoid recomputing earlier key/value states.

## 🧪 Practical Tasks — Task 1 to Task 6

### Task 1 — Introduction, History, Pipelines and Tokenizer

This section runs sentiment analysis on five sentences, summarises key Transformer milestones, lists impacts and disadvantages, inspects tokenizer output, demonstrates padding, and prints model configuration and parameter names.

**Expected outputs:** Sentiment labels and scores, token IDs, attention masks, model configuration table and parameter names.

### Task 2 — Self-Attention and Scaled Dot-Product Attention

This section implements Query, Key and Value projections in NumPy, calculates scaled attention, plots a 4 × 4 attention matrix, tests the scaling factor, implements Luong dot attention, demonstrates order-blindness, and inspects attention returned by a pretrained model.

**Expected outputs:** Intermediate tensor shapes, attention heatmap, row-sum check and scaling comparison.

### Task 3 — Multi-Head Attention, Positional Encoding and LayerNorm

This section visualises selected attention heads, measures attention entropy, creates a sinusoidal positional-encoding heatmap, compares the same embedding at two positions, inspects learned position embeddings, and compares NumPy LayerNorm with PyTorch LayerNorm.

**Expected outputs:** Attention-head grid, entropy chart, positional-encoding heatmap and normalization checks.

### Task 4 — Encoder Architecture and Masked Self-Attention

This section inspects encoder modules and parameter groups, runs fill-mask predictions, visualises bidirectional attention, implements a causal mask from scratch, and inspects GPT-2 attention.

**Expected outputs:** Parameter distribution chart, fill-mask predictions, bidirectional attention heatmap and causal mask.

### Task 5 — Cross-Attention, Decoder Architecture and Inference

This section uses T5 for translation and summarization, plots cross-attention, implements manual greedy decoding with GPT-2, compares decoding strategies, and measures generation time with and without the KV cache.

**Expected outputs:** Translation text, summary, cross-attention heatmap, decoding comparison table and timing results.

### Task 6 — Mini Application, Evaluation and Disadvantages in Practice

This section evaluates the sentiment model on 200 IMDB reviews, compares token limits of 64, 128, 256 and 512, measures forward-pass time at different sequence lengths, checks factual prompts, and combines sentiment analysis, summarization and French translation in `text_toolkit()`.

**Expected outputs:** Accuracy, precision, recall, F1, confusion matrix, truncation plots, sequence-time plot, factual-generation outputs and toolkit DataFrame.
